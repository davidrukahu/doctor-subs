# Doctor Subs v2 — Design Brief

Folder of context for Claude Design (https://claude.ai/design). Drop these files (or paste their contents) in the order listed below. Each file is self-contained but reads faster in sequence.

## Files, in order

1. **`01-product.md`** — what Doctor Subs is, who uses it, the emotional arc.
2. **`02-aesthetic.md`** — visual direction, references, anti-references (what it should NOT look like).
3. **`03-surfaces.md`** — the five screens to design, with layout and content specs.
4. **`04-states.md`** — interaction states per surface (loading, empty, error, success).
5. **`05-copy.md`** — draft copy for every label, button, message, empty state, error.
6. **`06-constraints.md`** — technical container (WP admin plugin), accessibility, responsive.

## The ask in one sentence

Design five connected surfaces for a WordPress plugin that helps a non-technical WooCommerce store owner find and fix broken subscriptions without calling support. The feel should be calm, clinical, modern, confident. Think Linear, Plausible, WHOOP, Apple Health. Not SaaS loud, not dated WP admin.

## What success looks like

- The merchant opens the plugin panicked (revenue dip noticed). They feel calmer by the time they've scanned.
- The dashboard tells them "you're OK" or "here are three things" in less than 3 seconds of looking.
- Every fix action is reassuring: they see exactly what will change before they click.
- The whole thing fits inside `/wp-admin/` but feels like its own product, not a stock plugin template.

## What to avoid

- AI-generated SaaS aesthetic (gradient backgrounds, purple/violet, icons-in-colored-circles, 3-column feature grids, centered-everything, generic dashboard hero-metric layouts).
- Dated WordPress styling (flat WP blue buttons, cramped 14px everything, 4px border-radius, #f6f7f7 gray washes).
- Stock "health" patterns (traffic-light literalness: giant red/amber/green colored blocks).
- Decorative fluff (floating blobs, wavy dividers, emoji as design, big empty hero images).

## What I'd love to see

- Typography that feels considered and characterful — not Inter, not Plex, not DM Sans. Pick something less worn.
- Tinted neutrals (slight hue wash on the whites and grays, not pure #fff / #eee).
- Generous negative space that says "this is a calm tool, take your time."
- One hero moment per surface — one thing that makes the page memorable and feel like it belongs to THIS product.
