Settings

Alerts

When something breaks between scans, we&rsquo;ll email you a daily digest. Off by default.
When new broken subscriptions appear, you&rsquo;ll get a daily summary email.
Defaults to your WordPress admin email.

Fix history retention

Older entries get pruned automatically. Recent entries stay revertible.
Fixes older than this stay in your history for reference, but the Revert button is removed. They are not deleted from the database unless you prune manually.
Older fixes stay in your history but can&rsquo;t be reverted anymore.

Help us improve

Anonymous telemetry helps us know which fixes are actually used. We only send the rule name and a timestamp when a fix is applied. Nothing else - no customer data, no subscription details, no identifying information.
Three fields only: (1) the rule name (e.g. ghost_sub), (2) an anonymous install hash, (3) a timestamp. We never see your store URL, customer data, subscription details, or store name.
Off by default. Turn it on if you want to help us build the plugin better.
