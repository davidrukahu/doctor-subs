# Design Context

### Users

Solo, non-technical WooCommerce store owner running a subscription business (20-500 active subscribers). Discovers problems via revenue dip or a customer email, not by reading logs. Cannot run WP-CLI. Opens the plugin in panic mode (first visit) or as a Monday-morning habit (return visits). Cannot distinguish Action Scheduler from DNS.

Job to be done: tell me in 5 seconds whether my store is OK, and if not, give me a button I can trust to fix the three specific broken-subscription patterns the plugin detects.

### Brand Personality

Three words: **Calm. Clinical. Confident.**

Voice: direct and kind, like a good doctor. Never salesy. Never cutesy. No "" / "awesome". No emoji. No exclamation points. Short sentences. Plain English that the 50-year-old shop owner understands.

Emotional goals: lower heart rate on first visit. Confirm OK or show exactly three items on return visits. Never surprise. Never mislead. Explicit about what fixes can and cannot do.

### Aesthetic Direction

Modern admin plugin that lives inside `/wp-admin/` but does not read as stock WP admin. References: Linear, Plausible Analytics, Stripe dashboard (modern era), WHOOP web app, Apple Health. Editorial type-led, not SaaS-card-mosaic.

Anti-references: dated WP admin (4px radius, flat WP blue buttons, 14px-everything), AI-SaaS hero gradients, healthcare-portal panic red, cookie-cutter dashboard widget grids, glass-morphism.

Theme: light. Tinted neutrals (hue 200-210, cool wash). Pure white/black banned. Single accent color: deep desaturated teal `oklch(48% 0.06 195)`. State colors tint-matched and calm: muted green (healthy), warm amber (at-risk), terracotta not alert-red (broken). OKLCH throughout.

Typography: Switzer (body grotesque), Instrument Serif (display moment, used sparingly), JetBrains Mono (sub IDs, numerics). All self-hosted woff2 per WP.org rules.

### Design Principles

1. **Never surprise the merchant.** Every fix shows a named diff (before -> after) before it applies. Every action is reversible via a fix journal. When revert cannot fully undo a side-effect (e.g. a payment already ran), say so explicitly in the modal.
2. **Calm over cheer.** An all-healthy state reads "Everything looks good. We'll keep watching." No confetti, no emoji, no "Great job!". The counters stay quiet. The tone matches a diagnostic tool, not a marketing page.
3. **Subtract decoration. Keep signal.** Motion only where it reinforces meaning (scanning pulse, apply/revert transitions). Shadows almost invisible. No decorative blobs, no wavy dividers, no border-left stripes as accents. The brand mark breathes subtly; everything else holds still.
4. **Scoped always.** All styles live under `.ds-root` so nothing leaks into the WP admin chrome or other plugins. WordPress renders the admin shell; the plugin owns only its content area.
5. **Accessibility is a constraint, not a polish pass.** 44px touch targets on mobile, WCAG 2.1 AA contrast, visible focus distinct from hover, aria-labels on icon-only buttons, `prefers-reduced-motion` respected at the tokens level.
